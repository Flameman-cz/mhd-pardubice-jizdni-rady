# Jízdní řády Pardubice

Datový zdroj pro aplikaci Jízdní řády Pardubice. Soubor `manifest.json` určuje aktuální podepsanou verzi přepočtenou z CIS JŘ a název příslušného datového ZIPu.

Každé vydání obsahuje pouze ověřená data. Při publikaci se nejprve nahraje balíček a teprve potom manifest. Čas zveřejnění se řídí dostupností nových, ověřených jízdních řádů.
